## 一个小点子

最初的要求很简单：**用 SVG 绘制一只骑自行车的鹈鹕，放进一个 HTML 页面，并让它动起来。**

于是有了这趟海边骑行：奶白色羽毛、金黄色大嘴、绿色围巾、橘红色自行车，还有远处的灯塔和帆船。没有关卡，也没有终点；今天的目的地，是没有目的地。

## 一位旅伴，许多种可能

现在，这段小动画是一座可以自由搭配的旅行小剧场，保留原来的奶油色纸面、深绿色线条与橘红色自行车。

- **角色**：人、鹈鹕、猫、兔子、熊、狐狸、狗、熊猫、青蛙和企鹅。头、身体和腿独立选择，也可以一键使用整套预设或随机搭配。头部自动接入所选身体的颈部，尾巴随身体一起变化；腿型包含鸟类细胫、猫狐趾行、兔子长后足、熊的厚爪和青蛙蹼足等区别。
- **穿搭**：自然模样与六种发型，轻装与八种服装，六种衣服颜色，原生脚掌与五种鞋子。围巾、眼镜、草帽和背包可以叠加。
- **运动**：骑自行车、跑步、划艇。换运动时会保留角色、穿搭与世界设置。
- **场景**：海岸、森林、沙漠、城市。划艇分别经过海面、草丛、沙丘、游泳池，尾迹随地表改变。每个场景有五项背景元素，分为远、中、近景，每层选择一个或留白；随机环境每层选一个。
- **世界**：春、夏、秋、冬，以及晴天、多云、下雨、飘雪、薄雾，任意组合。春日有花瓣，秋日有落叶，夏夜有萤火，冬季有银白海岸。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 顶部随机旅伴 | 随机角色和穿搭，保留环境 |
| 顶部随机环境 | 随机场景、季节、天气、时间和背景元素，保留旅伴与运动项目；暂停自动昼夜循环 |
| 远景 / 中景 / 近景 | 每层选择一个背景元素，也可选择“留白”；切换场景会保留各自的选择 |
| 开启音乐 / 关闭音乐、音量 | 播放原创背景音乐，随场景与天气切换；默认关闭，音量调到 0 即静音 |
| 角色 / 穿搭 / 世界 | 切换右侧设置；手机上设置面板位于场景下方 |
| 自行车 / 跑步 / 划艇 | 切换动作与设备 |
| 歇一会儿 / 继续出发 | 暂停或继续角色运动，天气与昼夜独立运行 |
| 运动速度 | 0.25× 到 2×，控制角色、车轮和经过的路面；每个倍率的基础速度均为 v2 的两倍 |
| 时间滑块 | 拨动到一天中的任意分钟，并暂停自动循环 |
| 自动循环 | 连续经过白天、黄昏、夜晚与清晨，再回到第二天 |
| 时间流速 | 0.25×、0.5×、1×、2×、4×；**1× 是现实 1 分钟走完一天** |
| 声音按钮 | 根据运动播放车铃、节拍或水花音效，只在点击后播放 |
| 回到最初 | 恢复夏日晴天、10:30、原始鹈鹕骑行与默认速度 |

初始时间停在 10:30，点击“自动循环”开始走时；运动速度与时间流速互不影响。页面隐藏时暂停计时，返回后继续，不会突然跳到另一时刻。

电脑和手机都可以直接打开。键盘使用 Tab 选择控件，方向键调整滑块或切换设置页签，空格、Enter 操作按钮。系统开启“减少动态效果”时，初始运动、天气动态和自动循环暂停；仍可手动换装、换天气或拨动时间，也可主动开始运动。

## 画面是怎么动起来的

角色、运动设备、海岸与天空都由 SVG 绘制。头、身体、腿、服饰是独立图层；各物种使用自己的颈部落点、躯干轮廓、尾巴和腿部比例，身体旋转时头颈一起运动，尾巴随运动轻摆。不同腿型共用脚掌接触位置：骑行的双脚跟随相对的脚踏；跑步时脚掌交替落地与抬起；划艇时双手始终握在同一根桨杆上。

运动、天气与昼夜使用独立的计时状态。昼夜按实际经过的秒数推进，不依赖动画帧数；天空和海面颜色平滑变化，日月、星光随时刻显现。季节改变植被、地面与飘落物，天气增加云层、雨、雪或雾，不会强制改变季节选择。

大背景的山丘、沙丘和天际线保持固定；远景、中景、近景分别以路面速度的 **10%、36%、72%** 向后经过。路面按角色前进速度移动，划艇表面由后向前逐渐加快至同一速度。各层跟随运动暂停与调速，天气和昼夜仍然独立。建筑、树木和花草以底部落在各自的地面上，帆船接触远处海面，风筝、蝴蝶和热气球则留在空中。

## 风景与配乐

| 场景 | 远景 | 中景 | 近景 | 原创循环旋律 |
| --- | --- | --- | --- | --- |
| 海岸 | 帆船 / 海鸥 / 风筝 | 灯塔 | 遮阳伞 | 海风小调：明亮的五声音阶与轻柔分解和弦 |
| 森林 | 蝴蝶 | 松树 / 木屋 | 蘑菇 / 野花 | 林间木语：留白较多的柔和旋律 |
| 沙漠 | 金字塔 / 热气球 | 绿洲棕榈 / 遗迹 | 仙人掌 | 沙丘来信：缓慢的小调动机 |
| 城市 | 高楼 | 咖啡馆 / 电车 | 街灯 / 喷泉 | 街角午后：轻快的切分节拍与低音 |

音乐由浏览器合成，不需要下载音频文件。多云、雨、雪和雾会改变速度、明暗与音符延音，雨天加入短促滴答，雪天加入高音点缀；切换环境后从接下来的音符自然进入新编配。离开页面时停止排音，返回后继续；音乐独立于运动和昼夜速度。
