## 一个小点子

最初的要求很简单：**用 SVG 绘制一只骑自行车的鹈鹕，放进一个 HTML 页面，并让它动起来。**

于是有了这趟海边骑行：奶白色羽毛、金黄色大嘴、绿色围巾、橘红色自行车，还有远处的灯塔和帆船。没有关卡，也没有终点；今天的目的地，是没有目的地。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 歇一会儿 / 继续出发 | 暂停或继续动画 |
| 骑行速度 | 在 0.5× 到 2× 之间调整速度 |
| 叮铃铃 | 按响车铃，并显示铃声线条 |

电脑和手机都可以直接打开。键盘可以用 Tab 选择按钮与滑块，再用 Enter、空格或方向键操作。声音只在点击车铃后播放。

## 画面是怎么动起来的

鹈鹕、自行车、海岸与天空都由 SVG 图形绘制。脚踏、双腿、车轮和移动的路面使用同一个动画时钟；腿部根据脚踏位置弯曲，让脚始终跟随踏板。

云、海面、岸边和前景以不同速度经过，形成远近层次。身体随着踩踏轻微起伏，围巾随风摆动，鹈鹕偶尔眨眼。
