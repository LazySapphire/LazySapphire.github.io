## 一个小点子

最初的要求很简单：**用 SVG 绘制一只骑自行车的鹈鹕，放进一个 HTML 页面，并让它动起来。**

于是有了这趟海边骑行：奶白色羽毛、金黄色大嘴、绿色围巾、橘红色自行车，还有远处的灯塔和帆船。没有关卡，也没有终点；今天的目的地，是没有目的地。

## 一位旅伴，许多种可能

v2 把这段小动画扩展成一座可以自由搭配的海岸运动小剧场，保留原来的奶油色纸面、深绿色线条与橘红色自行车。

- **角色**：人、鹈鹕、猫、兔子、熊和狐狸。头、身体和腿独立选择，也可以一键使用整套预设或随机搭配。
- **穿搭**：自然模样与四种发型，轻装与四种服装，六种衣服颜色，原生脚掌与三种鞋子。围巾、眼镜、草帽和背包可以叠加。
- **运动**：骑自行车、跑步、划艇。换运动时会保留角色、穿搭与世界设置。
- **世界**：春、夏、秋、冬，以及晴天、多云、下雨、飘雪、薄雾，任意组合。春日有花瓣，秋日有落叶，夏夜有萤火，冬季有银白海岸。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 角色 / 穿搭 / 世界 | 切换右侧设置；手机上设置面板位于场景下方 |
| 自行车 / 跑步 / 划艇 | 切换动作与设备 |
| 歇一会儿 / 继续出发 | 暂停或继续角色运动，天气与昼夜独立运行 |
| 运动速度 | 0.25× 到 2×，控制角色、车轮和经过的路面 |
| 时间滑块 | 拨动到一天中的任意分钟，并暂停自动循环 |
| 自动循环 | 连续经过白天、黄昏、夜晚与清晨，再回到第二天 |
| 时间流速 | 0.25×、0.5×、1×、2×、4×；**1× 是现实 2 分钟走完一天** |
| 声音按钮 | 根据运动播放车铃、节拍或水花音效，只在点击后播放 |
| 回到最初 | 恢复夏日晴天、10:30、原始鹈鹕骑行与默认速度 |

初始时间停在 10:30，点击“自动循环”开始走时；运动速度与时间流速互不影响。页面隐藏时暂停计时，返回后继续，不会突然跳到另一时刻。

电脑和手机都可以直接打开。键盘使用 Tab 选择控件，方向键调整滑块或切换设置页签，空格、Enter 操作按钮。系统开启“减少动态效果”时，初始运动、天气动态和自动循环暂停；仍可手动换装、换天气或拨动时间，也可主动开始运动。

## 画面是怎么动起来的

角色、运动设备、海岸与天空都由 SVG 绘制。头、身体、腿、服饰是独立图层，共用运动关节位置：骑行的双脚跟随相对的脚踏；跑步时脚掌交替落地与抬起；划艇时双手始终握在同一根桨杆上。

运动、天气与昼夜使用独立的计时状态。昼夜按实际经过的秒数推进，不依赖动画帧数；天空和海面颜色平滑变化，日月、星光随时刻显现。季节改变植被、地面与飘落物，天气增加云层、雨、雪或雾，不会强制改变季节选择。
