## 为什么做这个游戏

这次尝试始于一个简单的问题：让 AI 做一个有趣的小游戏，会做出什么？我们先找了几个具有鲜明机制的独立游戏，最后选中了“和过去的自己合作”。

我选择了方向，并决定把成品放进个人站点。Codex 辅助完成了代码、原创关卡、界面和测试。本次会话中由我明确选择的模型配置是 **`gpt-6-astra`，推理强度 `xhigh`**。这里保留这个配置和作品的实际验证记录，便于以后回看和比较。

玩法灵感包括 [Chronotron](https://www.kongregate.com/en/games/scarybug/chronotron) 的时间协作机制；本作的关卡、代码、界面和程序绘制图形均为本次制作，没有使用原作素材。

## 怎么玩

先走到开关上，按 **E** 留下一个分身。你会回到起点，而它会重演刚才的行动。等它停在开关上，你就可以穿过已经打开的门。

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D 或 ← / → |
| 跳跃 | 空格、W 或 ↑；按住跳得更高 |
| 转动附近可动镜面 | F；每按一次转动一次 |
| 留下分身并回溯 | E |
| 重试当前一轮，保留分身 | R |
| 撤回最近一个分身 | Z |
| 暂停 / 继续 | P 或 Esc |
| 玩法说明 | ? |

手机和窄屏窗口提供移动、跳跃、交互按钮；桌面键盘更适合精细操作。声音默认关闭，可以在游戏右上角打开。

每关最多留下 **3 个分身**。前三章每轮 **24 秒**，后两章每轮 **32 秒**。已有分身在每轮开始时都从第 0 秒播放；开始行动才会启动时间，等待也会录进操作序列。

**现在的你和分身都可以推箱子、站在移动箱子上、乘升降台。** 分身之间及其与玩家之间可以穿过；它们回放的是操作，而不是一条不可改变的坐标轨迹。因此，箱子或闸门状态变了，同样的操作也可能走出不同的路线。录制结束后停止操作，但仍受重力和场景影响。

回溯或重试会复位箱子、镜面、升降台及所有开关，包括已经记忆或耗尽的一次性开关。红色危险区会让当前角色失败；分身碰到它会在本轮失效，不再压开关，但不会直接结束玩家的这一轮。金色实验光束无伤害。

**25 关全部开放**，通过游戏上方的“关卡目录”自由选择。切换关卡会清空当前分身，已通关标记保留。游戏内可复制当前关卡链接，例如直接挑战[第 25 关：众声成光](/games/echo-lab/#room=25)。

## 七种机关语言

| 符号 | 机关 | 激活与失效规则 |
| --- | --- | --- |
| — | 压力开关 | 角色、分身或箱子持续压住才亮 |
| ▣ | 配重开关 | 只认箱子，不认角色或分身 |
| ◎ | 感应开关 | 附近有角色才亮；空中的开关需要起跳接近 |
| ∞ | 记忆开关 | 角色碰一次便持续激活，直到本轮结束 |
| ◷ | 一次性定时开关 | 首次接近后开始倒计时，耗尽后本轮不能再次激活或延时 |
| ⇆ | 运动供能跑道 | 角色在跑道上落地且实际移动才充能；停止后衰减，顶墙按键不算运动 |
| ☼ | 光接收器 | 只认光束；箱子、实体墙和关闭的门挡光，镜面改变光路 |

镜面分为可动镜和标有 `FIX` 的固定镜。可动镜可以在 `/` 与 `\` 间切换，分身也会重演转镜操作。部分光源需要运动跑道持续供电。机关状态、剩余时间、充能量会同时显示在场景和侧栏里。

## 制作与验证记录

**2026-09-06 · v2.0.0**

- 用户提出让分身真正接触箱子，并加入至少 20 个进阶关卡、跳跃感应、记忆、一次性计时、外物激活、持续运动机关与自由选关。
- 先建立分身推箱回归测试：旧版原角色把箱子推到约 650，分身重播后箱子仍在 520。将“坐标回放”改为“操作回放 + 共享物理”，测试转为通过；新增箱顶载人、分身乘梯与转镜回放。
- 保留原五关的编号与存档位置，新增 20 关，形成五章 25 关。关卡数据独立维护在 `levels.js`，不引入第三方依赖。
- 实现七类机关、真实遮挡与镜面反射、供能光源、机关剩余时间/充能状态、章节配色、全开放目录及带关卡编号的分享链接。
- 25 关均用正常移动、跳跃、等待、交互、记录操作通过自动通关测试，不通过修改角色位置或强制开门来通关。另测分身推箱、载人、开关类型判定、不可续期、回溯复位、运动衰减、顶墙、镜面按键边沿与回放、光路遮挡/循环上限和门框防夹。
- 自审发现并修复“分身推箱把玩家挤入闭门、误触发防夹开门”的边界问题，保留实际操作回归；独立复查和全部通关测试通过。
- 浏览器实测键盘转镜、分身转镜回放及第 22 关通关；验证跳跃感应的亮灭、触屏移动/交互、自由选关、进度保存、当前关卡链接复制、帮助关闭和减少动态效果。320 / 375 / 844 / 1024 / 1440 px 布局均无横向溢出。

**2026-09-06 · v1.0.0（历史版本）**

- 完成五个原创关卡，以及角色移动、可变高度跳跃、机关门、箱子、往返升降台和激光。
- 实现固定 60 Hz 的游戏逻辑。分身保存并播放位置记录，避免后来改变的场景导致原有轨迹漂移。

- 五关均使用正常移动、跳跃输入完成自动通关验证；检查分身停留、回放不变性、撤回、重试、录制上限、落地条件、激光判定和闸门防夹。
- 在浏览器里实际走通前两关，验证创建两个分身、通关弹窗、解锁和存档衔接，并检查提示、暂停、重试与 375 px 窄屏布局。
- 将游戏迁入个人站点，新增本栏目、独立游玩地址和这份制作记录。

自动通关证明每关至少有一条可行路线，并不代表穷尽了所有玩家操作。手感、难度曲线与提示仍欢迎实际游玩反馈。

## 源码与存档

游戏使用 HTML、CSS 和原生 JavaScript Canvas，没有运行时第三方依赖。代码位于[站点仓库的游戏目录](https://github.com/LazySapphire/LazySapphire.github.io/tree/main/static/games/echo-lab)，对应的[逻辑测试](https://github.com/LazySapphire/LazySapphire.github.io/blob/main/scripts/tests/echo-lab.cjs)可以在仓库根目录运行：

```bash
node scripts/tests/echo-lab.cjs
node scripts/tests/echo-lab-physics.cjs
```

游戏进度只保存在当前浏览器的本地存储中，不需要账号，不会上传存档。换浏览器、清除网站数据或使用另一台设备时，进度不会自动同步。
