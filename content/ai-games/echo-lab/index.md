## 为什么做这个游戏

这次尝试始于一个简单的问题：让 AI 做一个有趣的小游戏，会做出什么？我们先找了几个具有鲜明机制的独立游戏，最后选中了“和过去的自己合作”。

我选择了方向，并决定把成品放进个人站点。Codex 辅助完成了代码、原创关卡、界面和测试。本次会话中由我明确选择的模型配置是 **`gpt-6-astra`，推理强度 `xhigh`**。这里保留这个配置和作品的实际验证记录，便于以后回看和比较。

玩法灵感包括 [Chronotron](https://www.kongregate.com/en/games/scarybug/chronotron) 的时间协作机制；本作的关卡、代码、界面和程序绘制图形均为本次制作，没有使用原作素材。

## 怎么玩

先走到开关上，按 **E** 留下一个分身。你会回到起点，而它会重演刚才的行动。等它停在开关上，你就可以穿过已经打开的门。

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D 或 ← / → |
| 跳跃 | 空格、W 或 ↑；按住跳得更高 |
| 留下分身并回溯 | E |
| 重试当前一轮，保留分身 | R |
| 撤回最近一个分身 | Z |
| 暂停 / 继续 | P 或 Esc |
| 玩法说明 | ? |

手机和窄屏窗口提供移动、跳跃按钮；桌面键盘更适合精细操作。声音默认关闭，可以在游戏右上角打开。

每关最多留下 **3 个分身**，每段记录最长 **24 秒**。录制结束后，分身会停在原地并继续压住开关。已有分身在每轮开始时都从第 0 秒播放；开始移动才会启动时间。

现在的你可以直接推动箱子。分身互不碰撞，也不会重新推动箱子。箱子和升降台会在每轮开始时复位。红色激光会中断当前一轮，但已有分身可以保留。

## 五个房间

| 房间 | 名称 | 新的挑战 |
| --- | --- | --- |
| 01 | 第一次回声 | 留下一个分身，帮自己开门 |
| 02 | 两个人的接力 | 为两道闸门安排先后协作 |
| 03 | 一点重量 | 高处开关、箱子配重与激光 |
| 04 | 托举 | 升降台与上下两层之间的合作 |
| 05 | 我们，一起 | 三个分身共同完成最后的实验 |

游戏内每关都有可展开的提示。失败可以重试，也可以撤回最近的分身重新安排。

## 制作与验证记录

**2026-09-06 · v1.0.0**

- 完成五个原创关卡，以及角色移动、可变高度跳跃、机关门、箱子、往返升降台和激光。
- 实现固定 60 Hz 的游戏逻辑。分身保存并播放位置记录，避免后来改变的场景导致原有轨迹漂移。
- 加入时间轨迹显示、逐关解锁、本地存档、失败恢复、声音开关、触屏操作和减少动态效果的偏好支持。
- 五关均使用正常移动、跳跃输入完成自动通关验证；检查分身停留、回放不变性、撤回、重试、录制上限、落地条件、激光判定和闸门防夹。
- 在浏览器里实际走通前两关，验证创建两个分身、通关弹窗、解锁和存档衔接，并检查提示、暂停、重试与 375 px 窄屏布局。
- 将游戏迁入个人站点，新增本栏目、独立游玩地址和这份制作记录。

这些检查覆盖了逻辑与基础交互；关卡是否有趣、提示是否够清楚，还需要朋友们实际游玩后的反馈。

## 源码与存档

游戏使用 HTML、CSS 和原生 JavaScript Canvas，没有运行时第三方依赖。代码位于[站点仓库的游戏目录](https://github.com/LazySapphire/LazySapphire.github.io/tree/main/static/games/echo-lab)，对应的[逻辑测试](https://github.com/LazySapphire/LazySapphire.github.io/blob/main/scripts/tests/echo-lab.cjs)可以在仓库根目录运行：

```bash
node scripts/tests/echo-lab.cjs
```

游戏进度只保存在当前浏览器的本地存储中，不需要账号，不会上传存档。换浏览器、清除网站数据或使用另一台设备时，进度不会自动同步。
