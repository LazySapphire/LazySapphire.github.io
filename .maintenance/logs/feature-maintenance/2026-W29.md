# Feature Maintenance - 2026-W29

## 2026-07-17 - 资料仓库 skill 栈与内容入口落地

背景:

- 个人主页仓库需要承担资料速记、论文速读、主题综述和后续精读入口的职责。
- 日常输入主要是链接、arXiv 页面、项目主页、公司资讯、开源项目和在线网站工具，不应默认依赖 PDF 或外部知识管理工具。
- 需要让后续 AI agent 能根据输入类型选择稳定的整理流程。

实施内容:

- 安装用户级外部 Codex skills: `paper-search`、`pdf`、`playwright`、`literature-review`。
- 安装 `paper-search-mcp` CLI，并验证 `paper-search` 命令可用。
- 新增仓库本地 skills:
  - `resource-intake-triage`
  - `paper-brief-publishing`
  - `topic-survey`
  - `repo-curation-maintenance`
- 新增公开内容栏目:
  - `content/resources/`
  - `content/paper-briefs/`
  - `content/surveys/`
- 新增对应 archetypes: `resource.md`、`paper-brief.md`、`survey.md`。
- 更新导航、首页栏目卡片、列表页和详情页，让资源类型、状态、来源、arXiv、项目链接等元信息可见。
- 更新 `README.md`、`.ai/AGENTS.md` 和 `docs/guide_资料整理与技能使用指南.md`。

决策:

- `resources` 作为非论文资料的默认入口，覆盖产品资讯、开源项目、在线工具、技术文章和 Demo。
- `paper-briefs` 作为论文链接的默认入口，只有进入精读后才整理到 `papers`。
- `surveys` 采用轻量主题综述，不默认使用重型系统综述流程。
- `literature-review` 已安装但仅在正式系统综述场景使用。

验证:

- `paper-search sources`
- `paper-search search "diffusion models" -n 1 -s arxiv`
- `quick_validate.py` 校验四个新增本地 skill。
- `.tmp/hugo-bin/usr/local/bin/hugo --minify --gc`
- `scripts/check-production-artifacts.sh public`
