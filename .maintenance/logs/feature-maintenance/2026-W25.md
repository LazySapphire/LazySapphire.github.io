# Feature Maintenance - 2026-W25

## 2026-06-15 - 论文 PDF 资产仓库与本地按需获取流程落地

背景:

- 论文阅读笔记需要长期保留原始 PDF，方便后续校对和更新。
- 这些 PDF 不适合进入当前 Hugo 站点仓库历史，也不应该默认同步到每台维护机器。
- 网站访问时不需要提供 PDF 阅读入口，PDF 的职责仅限本地维护。

实施内容:

- 在 `config/_default/hugo.toml` 中新增 `[params.paper_assets]`，约定外部 PDF 仓库、archive 工作区、本地缓存目录和 LFS 维护参数。
- 为 `heracles-2603-27756`、`parc-2025`、`mugen-2605-24592` 增加 `pdf_asset` 与 `pdf_sha256` front matter。
- 从三篇公开论文笔记正文中移除 `PDF` 外链，保持网站只展示阅读笔记。
- 新增 `scripts/bootstrap-pdf-archive.sh`，用于在新机器上准备浅克隆且跳过 LFS 自动下载的 `pdf-archive` 工作区。
- 新增 `scripts/fetch-paper-pdf.py`，支持优先从本地 `pdf-archive` 工作区按需取 PDF，并校验 sha256。
- 将 `.cache/` 加入 `.gitignore`，使本地获取的 PDF 不进入 Git 历史。
- 更新 `README.md`、`.ai/AGENTS.md`、`paper-note-publishing` skill。
- 新增 `.ai/skills/paper-pdf-asset-maintenance/`，沉淀外部 PDF 资产维护流程。

决策:

- 采用“主仓库只存笔记与元数据，PDF 存外部 git 仓库，维护时按需拉取”的结构。
- 默认外部 PDF 仓库约定为 `LazySapphire/pdf-archive`，通过 Git LFS 管理 `papers/*.pdf`。
- 公开网页不再承担 PDF 分发职责。

验证:

- `python3 scripts/fetch-paper-pdf.py --dry-run --all`
- `python3 scripts/fetch-paper-pdf.py heracles-2603-27756`
- `hugo --minify --gc`
- `scripts/check-production-artifacts.sh public`

结果:

- 已创建并推送独立资产仓库 `LazySapphire/pdf-archive`。
- 已将当前三篇论文 PDF 上传到 `papers/` 目录，并由 Git LFS 追踪。
- 新机器只需克隆主仓库并执行 `git lfs install` 与 `scripts/bootstrap-pdf-archive.sh`，即可在不全量下载 PDF 的前提下继续维护。
